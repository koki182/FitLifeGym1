# FitLifeGym1

Part 2: CSS Styling and Responsive Design
Part 2 Details

Part 2 focused on improving the visual appearance and responsiveness of the FitLife Gym website. An external CSS stylesheet was created and linked to all HTML pages.

The purpose of Part 2 was to make the website more professional, consistent and easier to use on different screen sizes.

CSS Styling

The external stylesheet was used to:

Create a consistent colour scheme.
Improve the typography.
Add spacing between sections.
Style headings and paragraphs.
Style navigation links.
Create attractive buttons.
Add backgrounds and borders.
Style images.
Improve the layout of the website.
Add hover effects to interactive elements.

The CSS file is stored in the css folder.

css/
└── style.css
Typography

Different font sizes and font weights were used to create a clear hierarchy.

For example:

Large headings are used for page titles.
Smaller headings are used for individual sections.
Paragraph text is kept readable.
Buttons and navigation links are clearly visible.
Layout

CSS Flexbox and other layout properties were used to organise content on the pages.

The layout was designed to provide:

Clear spacing.
Consistent alignment.
Easy navigation.
Well-organised sections.
A professional appearance.
Responsive Design

Responsive design was added to allow the FitLife Gym website to adapt to different screen sizes.

The website was designed for:

Desktop computers.
Laptops.
Tablets.
Mobile phones.

CSS media queries were used to change the layout when the screen becomes smaller.

For smaller screens:

Content can change to a single-column layout.
Images resize to fit the screen.
Text sizes can be adjusted.
Navigation can become easier to use.
Sections have appropriate spacing.

The website was tested using browser developer tools to check how the pages appear at different screen sizes.
